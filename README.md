# 🌐 Infrastructure as Code: Go Application & Monitoring Deployment

Проект автоматизированного развертывания веб-приложения на Go с выделенным контуром мониторинга (Prometheus + Grafana). Инфраструктура описывается как код (IaC), а конфигурация серверов полностью управляется через инструменты управления конфигурацией.

## 🏗️ Архитектура проекта

Развертывание разделено на две изолированные виртуальные машины для обеспечения отказоустойчивости:
* **Server 1 (App Node):** Хост для Go-приложения, изолированного в Docker-контейнере.
* **Server 2 (Monitoring Node):** Сервер сбора метрик и визуализации. Prometheus собирает метрики приложения методом pull, Grafana используется для построения дашбордов.

## 🛠️ Стек технологий
* **IaC:** Terraform
* **Configuration Management:** Ansible
* **Контейнеризация:** Docker
* **Приложение:** Go (Golang)
* **Мониторинг:** Prometheus, Grafana

## 📂 Структура репозитория
```text
├── terraform/               # Инфраструктура как код
│   ├── main.tf              # Описание ресурсов (VM, сети, диски)
│   ├── variables.tf         # Переменные (опционально)
│   ├── outputs.tf           # Вывод IP-адресов
│   └── cloud_init.cfg       # Первичная настройка VM (пользователи, SSH)
├── ansible/                 # Управление конфигурацией
│   ├── playbook.yml         # Основной сценарий развёртывания
│   ├── hosts.ini            # Инвентарь (IP-адреса VM)
│   ├── templates/
│   │   └── prometheus.yml.j2 # Шаблон конфигурации Prometheus
│   └── files/
│       └── grafana.deb      # Установочный пакет Grafana (нужно скачать вручную)
├── app/                     # Исходный код Go-приложения
│   ├── main.go              # HTTP-сервер, отдаёт метрики
│   ├── Dockerfile           # Сборка образа приложения
│   └── go.mod               # Зависимости Go
└── README.md                # Документация проекта
```
## 🚀 Быстрый запуск

### 1. Подготовка окружения
Перед стартом убедитесь, что на локальной машине установлены `terraform` и `ansible`. Поместите установочный пакет Grafana (`.deb`) в директорию `ansible/files/` для обеспечения автономности деплоя.

### 2. Развертывание инфраструктуры (Terraform)
Перейдите в директорию Terraform, инициализируйте провайдер и примените конфигурацию для создания ресурсов и генерации output-переменных:

```bash
cd terraform/
terraform init
terraform apply -auto-approve
```

### 3. Конфигурация и Деплой (Ansible)
1. Перенесите полученные IP-адреса серверов из outputs в файл инвентаря `ansible/hosts.ini`.
2. Запустите идемпотентный плейбук для автоматической настройки среды:

```bash
cd ../ansible/
ansible-playbook -i hosts.ini playbook.yml
```

## 📊 Проверка работы и эндпоинты

* **Приложение:** `http://<APP_SERVER_IP>:8080`
* **Метрики Prometheus:** `http://<MONITORING_SERVER_IP>:9090`
* **Панели Grafana:** `http://<MONITORING_SERVER_IP>:3000` *(Log/Pass по умолчанию: admin/admin)*
